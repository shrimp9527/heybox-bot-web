# 更新日志

## 2026-06-29

### 一、启动状态与日志显示修复

- 程序启动时显式重置 `BotEngine` 运行状态为停止，避免前端显示上一次运行状态。
- SSE 日志流不再推送历史日志，仅推送连接后产生的新日志。
- 前端页面加载时主动调用 `/api/log/recent` 获取最近 20 条历史日志并渲染，确保启动自检等关键日志可见。
- 前端页面加载时立即刷新机器人状态，日志容器清空并显示"正在连接日志服务..."。
- 将登录状态检测、Steam 榜单时效检测、自动爬取启动等自检流程延迟到 Web 服务器启动后执行，使前端能实时看到完整自检过程。

### 二、Web 控制台视觉重构：黑盒指挥舱主题

- 重新设计整体布局：左侧边栏控制中心 + 右侧终端日志主区域。
- 采用深色终端风格，与操作日志流形成统一的「指挥舱」体验。
- 优化按钮、开关、输入框、提示文本等组件的暗色主题兼容性。

### 二、Steam 游戏榜单管理

#### 1. 本地数据库爬取优化

- 降低爬取频率，页间随机间隔 `1.5~2.5` 秒，减少触发 Steam 反爬风险。
- 每个分类按日期独立缓存，仅当该分类非今日更新时才重新爬取。
- 每个分类爬取完成后立即持久化到 `data/steam_local_db.json`，中途中断后可续爬。
- 请求失败时自动超时重试。

#### 2. 配置项扩展

- 新增 `steam.auto_scrape` 开关（默认 `true`），控制程序启动后是否自动后台更新榜单。
- 通过 `POST /api/config/steam` 可实时修改该开关。

#### 3. 后端 API

- `GET /api/steam/scrape/status`：返回各分类的更新日期、游戏数量、是否需要更新。
- `POST /api/steam/scrape/trigger`：手动触发后台爬取（`force=True`）。

#### 4. 前端榜单状态面板

- 在「机器人配置 → Steam 库存评价」区域新增「游戏榜单管理」面板。
- 支持开启/关闭自动爬取、立即爬取榜单、刷新榜单状态。
- 新增「Steam 游戏榜单状态」倒三角折叠组件，点击展开/收起各分类详情。
- 折叠组件复用现有 `toggleSearch` / `search-toggle` 交互模式，与暗色主题兼容。

### 三、日志系统改进

#### 1. 日志按日期分文件

- 日志文件不再全部写入单个 `data/bot.log`。
- 改为每日新建文件：`data/log/bot_YYYY-MM-DD.log`。
- 跨天时自动切换到新文件，无需重启服务。
- 旧 `data/bot.log` 保留但不再写入。

#### 2. 前端日志折叠

- **Steam 爬取日志**：连续多条 `[Steam 爬取]` 日志合并为一条 `[Steam 爬取] 展开 N 条 ▶`，点击后展开查看详情。
- **自检 Steam 榜单时效日志**：`[自检] 正在检测 Steam 游戏榜单时效...` 后的长串详情默认折叠，点击 ▶ 展开。
- 复用现有 `search-toggle` + `search-body` 折叠交互模式。

#### 3. 后端日志折叠

- `update_local_db` 中，今日已更新的分类不再逐条输出 `[Steam 爬取] xxx: 今日已更新，跳过`。
- 改为最终统一输出：`[Steam 爬取] 完成：跳过 N 个分类，共 X 款游戏`。
- 去除 `app.py` 中重复的 `[自检] 正在检测 Steam 游戏榜单时效...` 空日志。

### 四、Bug 修复

- 修复机器人启动状态不一致的问题。
- 修复 Token 消耗无法显示全部模型的问题。
- 修复 Steam 饼图缺失的问题。
- 新增检查状态、退出登录、重置配置功能。
- 修复账号切换失效的问题。

### 五、启动流程调整

启动顺序优化为：

1. 安装依赖
2. `[自检] 程序启动`
3. 检测登录状态
4. 检测 Steam 榜单时效（输出折叠日志）
5. 若开启 `steam.auto_scrape`，启动后台自动爬取
6. 启动 Web 服务器 `http://127.0.0.1:5500`
